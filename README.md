### CN2 GIA、9929、4837、CMIN2 分別是什麼

這些名詞指的是骨幹網線路類型，不是配置檔次。CN2 GIA 是電信的高端承載網，有專用信道，不跟普通流量擠；9929 是聯通的精品網；4837 是聯通普通國際線路的編號，常被包裝成「偽精品」；CMIN2 是移動的國際精品網；CMI 則是移動面向境外節點的線路。一家店能把這幾種湊齊，你就不用在三家服務商之間拼單。

線路的實際差別有多大？第三方測評在麗薩主機的美國 CN2 GIA 配置上測到，從國內連過去延遲落在 **160ms 到 180ms** 區間，對美國機房來說屬於正常偏好水平，高峰期沒有明顯丟包和抖動，原因是 CN2 GIA 有專用信道。這個數字比看十張帶寬圖都直觀：美國西海岸的物理延遲下限就在 130ms 到 150ms 之間，能穩定壓在 180ms 以內，說明路由沒繞路。

## 常見問題

**海外 VPS 需要備案嗎？**
不需要。機房在境外，不涉及大陸的 ICP 備案流程，買完就能綁域名上線。這是海外 VPS 相對國內雲伺服器最直接的優勢。

**CN2 GIA 和普通 BGP 差在哪？**
差在是否走專用信道。普通 BGP 線路在晚高峰要和大量流量搶帶寬，CN2 GIA 走的是電信高端承載網，優先級更高。實際表現是延遲更穩、丟包更少，而不是延遲數字更小，美國機房的物理延遲下限擺在那裡，160ms 到 180ms 已經是很不錯的成績。

**1核1G 夠用嗎？**
跑建站和各種輕量服務完全夠。真正拖慢體驗的是線路和磁盤 IO，不是 CPU 核心數。與其把預算花在從 1核升到 2核，不如先確認線路對不對。

**流量用完了會斷網嗎？**
美國 CN2 GIA 不限流量系列不存在這個問題，帶寬是硬上限、流量不設限。年付檔位的流量政策各商品頁不同，下單前逐一確認。

**可以換 IP 嗎？**
官網標示預設 1 個 IPv4 且可額外加購，更換 IP 的具體規則和費用沒有公開說明，需要開工單確認。對 IP 穩定性要求高的業務，這一項值得提前問。

**月付還是年付划算？**
先用月付跑一個月，確認延遲、丟包和穩定性符合預期，再轉年付。試錯成本應該花在月付上，不是年付上，這條建議適用於所有海外 VPS，不是麗薩主機的特殊要求。
